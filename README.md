# HyRouter

**Раздельная маршрутизация всей домашней сети через Hysteria 2 и VLESS — прямо на роутере с OpenWrt или на Кинетике.**

Телевизор целиком идёт через VPN, телефон — только YouTube, банки и Госуслуги — напрямую, реклама блокируется. На самих устройствах ничего настраивать не нужно: правила задаются один раз на роутере, в веб-интерфейсе.

HyRouter — версия [HyRoute](https://github.com/lardan099/HyRoute) для роутеров. Модель правил, разбор ссылок и подписок, группы серверов, DNS, статистика и обход DPI взяты из HyRoute. Вместо программ на компьютере правила различают устройства в сети.

> [!WARNING]
> **Бета.** v0.4.0 проверена только в CI: в сетевых пространствах имён Linux с настоящим сервером Hysteria 2 (обе редакции) и установкой пакетов в официальные образы OpenWrt 24.10 и 25.12. На настоящих роутерах она не проверялась. Ставьте её только туда, где сможете вернуть сеть: команда `/etc/init.d/hyrouter stop` по SSH снимает все правила HyRouter (с блокировкой при загрузке — ещё и `/etc/init.d/hyrouter-guard disable`).

## Две редакции

Обе собираются из одного кода и ставятся одинаково. Выберите редакцию по роутеру.

| | **HyRouter** | **HyRouter Lite** |
|---|---|---|
| Для каких роутеров | современные на aarch64 (MediaTek MT7981/MT7986, Qualcomm IPQ60xx/IPQ807x), x86_64 | слабые и старые: MIPS MediaTek MT7621, ARMv7 Qualcomm IPQ40xx |
| Например | Xiaomi AX3000T, Cudy WR3000, GL.iNet MT3000 | Xiaomi R3G, Xiaomi 4A Gigabit, Linksys EA6350, GL.iNet B1300 |
| Память | от 256 МБ RAM | 256 МБ RAM; на 128 МБ — с оговорками |
| Место | от 64 МБ свободно (флеш или USB) | от 16 МБ свободно |
| Протоколы | Hysteria 2 и VLESS | Hysteria 2 |
| Ядро | отдельный процесс `hysteria` (или `xray`) на сервер, скачивается при первом включении | клиент Hysteria внутри `hyrouterd` |
| Ограничения | — | кэш DNS 10 000 записей, до 3 работающих серверов группы, до 500 серверов из подписки, память демона ограничена |
| Пакет | `hyrouter` | `hyrouter-lite` |
| Архитектуры пакетов | `aarch64_cortex-a53`, `aarch64_cortex-a72`, `aarch64_generic`, `x86_64` | `mipsel_24kc`, `arm_cortex-a7_neon-vfpv4`, `arm_cortex-a7`, `arm_cortex-a9`, `arm_cortex-a15_neon-vfpv4` |

Скорость через VPN на слабом роутере ограничена процессором: Hysteria шифрует программно. На MT7621 ориентир — десятки Мбит/с. Прямой трафик идёт на полной скорости, потому что его решает ядро, а не HyRouter.

Совсем маленькие роутеры (MT7628/MT7620, 64 МБ RAM) не поддерживаются.

## Как это работает

```
устройство ──► роутер: nftables (таблица inet hyrouter)
                 ├─ напрямую ──► обычная маршрутизация, без HyRouter (обход DPI — nfqws2)
                 ├─ блок ──────► сброс соединения
                 └─ через VPN ─► TPROXY ─► hyrouterd ─► сервер или группа ─► Hysteria 2 / Xray
```

- Решение для каждого нового соединения принимает ядро: по устройству, адресу, порту и наборам адресов сайтов. Сети категорий geoip лежат прямо в этих наборах.
- Адреса сайтов узнаёт DNS HyRouter. Он стоит перед dnsmasq и раскладывает ответы по наборам правил, в том числе для категорий geosite.
- Через `hyrouterd` идёт только VPN-трафик и соединения, для которых нужно прочитать имя сайта (SNI). Сервер выбирается по правилу: сам сервер, член группы или первый работающий запасной. Если ни один не работает, соединение отклоняется и никогда не уходит напрямую.

Подробно — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

1. Узнайте архитектуру роутера: `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).
2. Скачайте пакет своей редакции и архитектуры со страницы [Releases](../../releases). Таблица «какой пакет ставить» — в заметках к выпуску.
3. Скопируйте пакет на роутер (`scp -O пакет root@192.168.1.1:/tmp/`) и установите:

   ```sh
   # OpenWrt 24.10
   opkg update && opkg install /tmp/hyrouter_0.4.0-1_aarch64_cortex-a53.ipk
   # OpenWrt 25.x
   apk update && apk add --allow-untrusted /tmp/hyrouter-0.4.0-r1_aarch64_cortex-a53.apk
   ```

4. Откройте `http://192.168.1.1:8088` (адрес вашего роутера) и войдите паролем root. Добавьте сервер по ссылке или подписку, назовите устройства, задайте правила и нажмите «Включить».

Обычная редакция скачивает ядро Hysteria 2 (и Xray для VLESS) с GitHub при первом включении и сверяет по SHA-256. Lite ничего не скачивает: клиент Hysteria встроен. `nfqws2` для обхода DPI входит в пакеты обеих редакций.

**Как всё выключить:** кнопка «Выключить» в интерфейсе или `/etc/init.d/hyrouter stop` по SSH. С включённой «Блокировкой при загрузке» остановка службы закрывает сеть до следующего запуска, поэтому выключайте HyRouter кнопкой в интерфейсе или командами `/etc/init.d/hyrouter-guard disable && nft delete table inet hyrouter_guard`. Удаление пакета снимает все правила; настройки остаются в `/etc/hyrouter`.

## Кинетик (KeeneticOS)

С v0.5.0 HyRouter работает и на роутерах Keenetic (и Netcraze) с KeeneticOS 4.x — тот же веб-интерфейс и те же правила. Свои программы на Кинетике работают через Entware, поэтому сначала нужен он.

1. В веб-интерфейсе Кинетика (раздел «Общие настройки», набор компонентов) установите компоненты **«Поддержка открытых пакетов»** (OPKG) и **«Модули ядра подсистемы Netfilter»**. На старых прошивках второй появляется только после компонента **«Протокол IPv6»**.
2. Установите Entware на USB-накопитель или во встроенную память по инструкции из справки Кинетика.
3. Зайдите в Entware по SSH (порт 222, пользователь `root`) и **смените пароль** командой `passwd`: стандартным паролем `keenetic` войти в HyRouter нельзя.
4. Узнайте архитектуру: `opkg print-architecture`. Пакет со страницы [Releases](../../releases):

   | Архитектура Entware | Роутеры | Пакет |
   |---|---|---|
   | `mipsel-3.4` | большинство моделей (MediaTek MT7621, MT7628) | `hyrouter-keenetic-lite` |
   | `mips-3.4` | некоторые модели | `hyrouter-keenetic-lite` |
   | `aarch64-3.10` | новые модели на ARM64 | `hyrouter-keenetic` |

5. Скопируйте пакет на роутер (`scp -P 222 -O пакет root@192.168.1.1:/opt/tmp/`), установите и откройте `http://192.168.1.1:8088` (адрес вашего Кинетика), войдите паролем root Entware:

   ```sh
   opkg update
   opkg install /opt/tmp/hyrouter-keenetic-lite_0.5.0-1_mipsel-3.4.ipk
   ```

Пакет сам ставит из Entware `iptables`, `ipset` и сертификаты. Интерфейс LAN по умолчанию — `br0` (домашний сегмент); гостевой сегмент можно добавить в настройках.

**Как всё выключить:** кнопка «Выключить» в интерфейсе или `/opt/etc/init.d/S99hyrouter stop` по SSH. С «Блокировкой при загрузке» остановка оставляет сеть закрытой: откройте её командой `/opt/sbin/hyrouterd -cleanup`. Удаление пакета (`opkg remove hyrouter-keenetic-lite`) снимает все правила; настройки остаются в `/opt/etc/hyrouter`.

**Чем Кинетик отличается от OpenWrt:**

- Блокировка при загрузке закрывает сеть только с запуска Entware: пока прошивка грузится и подключает накопитель, трафик идёт напрямую.
- Когда прошивка перестраивает свои правила (например, при переподключении к провайдеру), она убирает и правила HyRouter. HyRouter возвращает их сразу через хук прошивки и ещё раз проверяет каждые 15 секунд; в этот промежуток новые соединения могут пройти мимо HyRouter.
- DNS-фильтры Кинетика по отдельным устройствам видят роутер вместо устройства: имена сайтов прошивка получает от HyRouter. Общие настройки DNS прошивки (DoH, DoT, фильтр для всей сети) продолжают работать.
- Если обход DPI работает через раз, попробуйте выключить сетевой ускоритель Кинетика.
- На настоящем Кинетике эта версия ещё не проверялась.

## Разработка

```
cmd/hyrouterd/      демон на роутере
internal/ctl        контроллер: настройки → ядра, группы, relay, DNS, nftables, подписки, geo, статистика, обход DPI, копия
internal/nft        компилятор правил в таблицу inet hyrouter, наборы через netlink, блокировка при загрузке
internal/ipt        то же на iptables и ipset для Кинетика: цепочки HYR_*, восстановление после прошивки
internal/platform   отличия OpenWrt и KeeneticOS: пути, DNS роутера, устройства, WAN, вход
internal/relay      TPROXY: TCP и UDP через сервер или группу, чтение SNI и Host, записи соединений
internal/dnsd       DNS перед dnsmasq, адреса сайтов в наборы правил
internal/hycore     клиент Hysteria 2 внутри hyrouterd (HyRouter Lite)
internal/subs       загрузка и разбор подписок, слияние серверов
internal/web        API веб-интерфейса, вход паролем root
internal/…          правила, группы, geodata, статистика, обход DPI (многие — из HyRoute)
web/                веб-интерфейс на Svelte 5 (web/dist встроен в hyrouterd)
build/              закреплённые версии (deps.json), сборка пакетов, службы procd и Entware
test/netns.sh       интеграционный тест маршрутизации
docs/               архитектура, сверка с HyRoute, заметки к выпускам
```

- Go 1.27, `CGO_ENABLED=0`: статический бинарник для каждой архитектуры; Lite — с тегом `lite`, Кинетик — с тегом `keenetic`.
- Все проверки идут в GitHub Actions: `gofmt`, `go vet`, тесты с `-race` для обеих редакций, `govulncheck`, правила nftables через `nft -c`, `nfqws2 --dry-run` с каждой командной строкой, `svelte-check` и сборка интерфейса, маршрутизация в сетевых пространствах имён с настоящим сервером Hysteria 2 для обеих редакций, установка пакетов и блокировки при загрузке в образы OpenWrt 24.10 и 25.12; для Кинетика — правила через `iptables-restore --test`, маршрутизация на legacy iptables с перестройками таблиц прошивкой и установка пакета в Entware.
- Выпуск собирается по тегу `vX.Y.Z` (`.github/workflows/release.yml`) из коммита main с зелёным CI и заметками `docs/release-notes/vX.Y.Z.md`.
- Правила работы с репозиторием — в [CLAUDE.md](CLAUDE.md).
