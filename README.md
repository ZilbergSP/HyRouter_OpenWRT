# HyRouter

HyRoute для роутеров на OpenWrt: раздельная маршрутизация всей домашней сети
через серверы Hysteria 2 и VLESS. Телевизор — весь через VPN, телефон — только
YouTube, банки и Госуслуги — напрямую, реклама — в блок. На устройствах ничего
настраивать не нужно.

Статус: проектирование. План и устройство — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

- OpenWrt 24.10 и новее, aarch64 и x86_64.
- Правила по устройствам, сайтам, IP, портам и спискам geosite/geoip.
- Веб-интерфейс на самом роутере, вход паролем root.
- Ядра — официальные Hysteria 2 и Xray-core.
