# HyRouter

**Раздельная маршрутизация всей домашней сети через Hysteria 2 и VLESS — прямо на роутере с OpenWrt.**

Телевизор целиком идёт через VPN, телефон — только YouTube, банки и Госуслуги — напрямую, реклама блокируется. На самих устройствах ничего настраивать не нужно: правила задаются один раз на роутере, в веб-интерфейсе.

HyRouter — версия [HyRoute](https://github.com/lardan099/HyRoute) для роутеров. Модель правил, разбор ссылок и подписок, DNS и обход DPI взяты из HyRoute. Вместо программ на компьютере правила различают устройства в сети.

> [!WARNING]
> **Бета.** v0.1.0 проверена только в CI: в сетевых пространствах имён Linux с настоящим сервером Hysteria 2 и установкой пакетов в официальные образы OpenWrt 24.10 и 25.12. На настоящих роутерах она не проверялась. Ставьте её только туда, где сможете вернуть сеть: команда `/etc/init.d/hyrouter stop` по SSH снимает все правила HyRouter.

## Две редакции

Обе собираются из одного кода и ставятся одинаково. Выберите редакцию по роутеру.

| | **HyRouter** | **HyRouter Lite** |
|---|---|---|
| Для каких роутеров | современные на aarch64 (MediaTek MT7981/MT7986, Qualcomm IPQ60xx/IPQ807x), x86_64 | слабые и старые: MIPS MediaTek MT7621, ARMv7 Qualcomm IPQ40xx |
| Например | Xiaomi AX3000T, Cudy WR3000, GL.iNet MT3000 | Xiaomi R3G, Xiaomi 4A Gigabit, Linksys EA6350, GL.iNet B1300 |
| Память | от 256 МБ RAM | 256 МБ RAM; на 128 МБ — с оговорками |
| Место | от 64 МБ свободно (флеш или USB) | от 32 МБ свободно; меньше — ядро в RAM |
| Протоколы | Hysteria 2 и VLESS | Hysteria 2 |
| Ограничения | — | кэш DNS 10 000 записей, память демона ограничена |
| Пакет | `hyrouter` | `hyrouter-lite` |
| Архитектуры пакетов | `aarch64_cortex-a53`, `aarch64_generic`, `x86_64` | `mipsel_24kc`, `arm_cortex-a7_neon-vfpv4` |

Скорость через VPN на слабом роутере ограничена процессором: Hysteria и Xray шифруют программно. На MT7621 ориентир — десятки Мбит/с. Прямой трафик идёт на полной скорости, потому что его решает ядро, а не HyRouter.

Совсем маленькие роутеры (MT7628/MT7620, 64 МБ RAM) не поддерживаются: ядро Hysteria на них не помещается.

## Как это работает

```
устройство ──► роутер: nftables (таблица inet hyrouter)
                 ├─ напрямую ──► обычная маршрутизация, без HyRouter
                 ├─ блок ──────► сброс соединения
                 └─ через VPN ─► TPROXY ─► hyrouterd ─► Hysteria 2 / Xray ─► сервер
```

- Решение для каждого нового соединения принимает ядро: по устройству, адресу, порту и наборам адресов сайтов.
- Адреса сайтов узнаёт DNS HyRouter. Он стоит перед dnsmasq и раскладывает ответы по наборам правил.
- Через `hyrouterd` идёт только VPN-трафик и соединения, для которых нужно прочитать имя сайта (SNI). Если сервер недоступен, VPN-трафик отклоняется и никогда не уходит напрямую.

Подробно — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка

1. Узнайте архитектуру роутера: `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).
2. Скачайте пакет своей редакции и архитектуры со страницы [Releases](../../releases). Таблица «какой пакет ставить» — в заметках к выпуску.
3. Скопируйте пакет на роутер (`scp -O пакет root@192.168.1.1:/tmp/`) и установите:

   ```sh
   # OpenWrt 24.10
   opkg update && opkg install /tmp/hyrouter_0.1.0-1_aarch64_cortex-a53.ipk
   # OpenWrt 25.x
   apk update && apk add --allow-untrusted /tmp/hyrouter-0.1.0-r1_aarch64_cortex-a53.apk
   ```

4. Откройте `http://192.168.1.1:8088` (адрес вашего роутера) и войдите паролем root. Добавьте сервер по ссылке, назовите устройства, задайте правила и нажмите «Включить».

Ядро Hysteria 2 (и Xray для VLESS) HyRouter скачивает с GitHub при первом включении и сверяет по SHA-256.

**Как всё выключить:** `/etc/init.d/hyrouter stop` (до перезагрузки) или кнопка «Выключить» в интерфейсе. Удаление пакета тоже снимает все правила; настройки остаются в `/etc/hyrouter`.

## Разработка

```
cmd/hyrouterd/      демон на роутере
internal/ctl        контроллер: настройки → ядра, relay, DNS, nftables
internal/nft        компилятор правил в таблицу inet hyrouter, наборы через netlink
internal/relay      TPROXY: TCP и UDP через сервер, чтение SNI и Host
internal/dnsd       DNS перед dnsmasq, адреса сайтов в наборы правил
internal/web        API веб-интерфейса, вход паролем root
internal/…          правила, DNS, ядра, обход DPI (многие — из HyRoute)
web/                веб-интерфейс на Svelte 5 (web/dist встроен в hyrouterd)
build/              закреплённые версии (deps.json), сборка пакетов, служба procd
test/netns.sh       интеграционный тест маршрутизации
docs/               архитектура, сверка с HyRoute, заметки к выпускам
```

- Go 1.27, `CGO_ENABLED=0`: статический бинарник для каждой архитектуры; Lite — с тегом `lite`.
- Все проверки идут в GitHub Actions: `gofmt`, `go vet`, тесты с `-race` для обеих редакций, `govulncheck`, правила nftables через `nft -c`, `svelte-check` и сборка интерфейса, маршрутизация в сетевых пространствах имён с настоящим сервером Hysteria 2, установка пакетов в образы OpenWrt 24.10 и 25.12.
- Выпуск собирается по тегу `vX.Y.Z` (`.github/workflows/release.yml`) из коммита main с зелёным CI и заметками `docs/release-notes/vX.Y.Z.md`.
- Правила работы с репозиторием — в [CLAUDE.md](CLAUDE.md).
