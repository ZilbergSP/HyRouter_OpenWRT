В этом выпуске доделано всё, что в 0.1.0 было отложено: группы и запасные серверы, подписки, категории geosite и geoip, обход DPI в интерфейсе, соединения и статистика, резервная копия и блокировка при загрузке. HyRouter Lite теперь запускает Hysteria внутри себя, без отдельного процесса.

> [!WARNING]
> **Бета.** Проверена только в CI: в сетевых пространствах имён Linux с настоящим сервером Hysteria 2 (обе редакции) и установкой пакетов в официальные образы OpenWrt 24.10 и 25.12. На настоящих роутерах не проверялась. Ставьте её туда, где есть доступ по SSH: команда `/etc/init.d/hyrouter stop` снимает правила HyRouter. Если включена «Блокировка при загрузке», выполните ещё `/etc/init.d/hyrouter-guard disable && nft delete table inet hyrouter_guard`.

### Новое

- **Группы серверов.** Несколько серверов, из которых HyRouter сам выбирает рабочий: по порядку (с возвратом к первому), самый быстрый, по кругу, случайно или «закреплять сайт» (один сайт одного устройства — через один сервер). Задержку HyRouter измеряет сам. Группу можно выбрать в правиле, в «Всё остальное» и основной. Если в группе не работает ни один сервер, соединение отклоняется, а не идёт напрямую.
- **Запасные серверы и группы** у правила и у «Всё остальное». Если основной не может пропустить соединение, берётся первый работающий из списка.
- **Подписки.** Добавьте ссылку панели (Remnawave, Marzban и другие): HyRouter загрузит из неё серверы и будет обновлять их сам — раз в час, 6, 12 или 24 часа. Если панель не отвечает напрямую, подписка загружается через основной сервер. Правила и группы при обновлении продолжают указывать на те же серверы. Видны остаток трафика и срок, а панели с ограничением устройств видят роутер как одно устройство. Группа может включать все серверы подписки.
- **geosite и geoip в правилах.** Например, `geosite:ru-blocked`, `geosite:youtube` или `geoip:ru`. HyRouter скачивает базу во временную память, оставляет на роутере только категории из ваших правил и освобождает память. Новую категорию он скачивает сам, раз в сутки обновляет базу. Источник базы выбирается в настройках.
- **Обход DPI.** Новая страница: YouTube, Discord и свои сайты (имена, адреса, сети) открываются напрямую, без VPN, через nfqws2 из zapret2. Кнопка «Подобрать автоматически» проверяет методы с самого роутера и запоминает лучшие для сети. Самопроверка раз в 10 минут подбирает методы заново, если сервис перестал открываться. Любой сервис можно пустить через VPN — через основной сервер, выбранный сервер или группу, или по вашим правилам. nfqws2 входит в пакеты обеих редакций.
- **Соединения.** Живой список: какое устройство куда идёт, по какому правилу, через какой сервер, сколько передано. Нигде не сохраняется.
- **Статистика** по устройствам, серверам и группам за день, неделю, месяц. Какие сайты открывались, HyRouter не записывает.
- **Резервная копия.** Все настройки в одном файле. Перед восстановлением HyRouter показывает, что придёт и что не будет работать: например, правило, которое ведёт напрямую всю сеть. После восстановления можно «Вернуть как было».
- **Блокировка при загрузке** (Настройки). Пока роутер загружается или HyRouter перезапускается, устройства не выходят в интернет, и трафик «через VPN» не уходит напрямую. Сам роутер и интерфейс остаются доступны.

### HyRouter Lite

- **Hysteria внутри HyRouter.** Отдельного процесса `hysteria` больше нет, и ядро (около 24 МБ для MIPS) не скачивается ни на флеш, ни в память: работает один процесс вместо процесса на каждый сервер. Подключение настраивается так же, как в Hysteria: прыжки портов, обфускация, пин сертификата, скорость.
- В группе одновременно работают до 3 серверов: остальные HyRouter проверяет по одному и подменяет ими медленные. Из подписки берётся до 500 серверов, серверы VLESS пропускаются.

### Какой пакет ставить

Архитектуру роутера покажут `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).

| Роутер | Архитектура | Пакет |
|---|---|---|
| MediaTek MT7981/MT7986/MT7988/MT7622, Qualcomm IPQ60xx/IPQ807x | `aarch64_cortex-a53` | `hyrouter` |
| Raspberry Pi 4 | `aarch64_cortex-a72` | `hyrouter` |
| другие aarch64 | `aarch64_generic` | `hyrouter` |
| x86_64 | `x86_64` | `hyrouter` |
| MediaTek MT7621 | `mipsel_24kc` | `hyrouter-lite` |
| Qualcomm IPQ40xx | `arm_cortex-a7_neon-vfpv4` | `hyrouter-lite` |
| Qualcomm IPQ806x | `arm_cortex-a15_neon-vfpv4` | `hyrouter-lite` |
| Marvell mvebu и др. ARMv7 | `arm_cortex-a9`, `arm_cortex-a7` | `hyrouter-lite` |

```sh
# OpenWrt 24.10
opkg update && opkg install ./hyrouter_0.4.0-1_aarch64_cortex-a53.ipk
# OpenWrt 25.x
apk update && apk add --allow-untrusted ./hyrouter-0.4.0-r1_aarch64_cortex-a53.apk
```

Обновление с 0.1.0 сохраняет настройки в `/etc/hyrouter`. Пакет теперь зависит от `kmod-nft-queue` (для обхода DPI): `opkg` и `apk` поставят его сами.
