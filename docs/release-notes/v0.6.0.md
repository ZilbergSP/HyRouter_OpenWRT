На настоящем Кинетике работала 0.5.0, и найденные там ошибки обхода DPI исправлены здесь. Списки проверок для настоящих роутеров ещё не пройдены. Ставьте туда, где есть доступ по SSH, чтобы выключить HyRouter, если сеть перестанет работать:
> - OpenWrt: `/etc/init.d/hyrouter stop`, с «Блокировкой при загрузке» — ещё `/etc/init.d/hyrouter-guard disable && nft delete table inet hyrouter_guard`;
> - Кинетик: `/opt/etc/init.d/S99hyrouter stop`, с «Блокировкой при загрузке» — ещё `/opt/sbin/hyrouterd -cleanup`.

### Шаблоны правил

- **«Правила → Шаблоны».** Готовые схемы: «Через VPN только заблокированное», «Всё через VPN, кроме российского», RoscomVPN. Правила для сервисов: YouTube, Discord, Telegram, ChatGPT, Claude, все ИИ-сервисы, Instagram, Meta, X, Spotify, Netflix, Twitch, LinkedIn. Ещё российские списки, реклама и телеметрия Windows.
- **Шаблон** открывается как новое правило: выберите устройства (ни одного — вся сеть) и сервер, затем нажмите «Готово».
- **Схема** ставит свои правила в начало списка, для всех устройств, и меняет «Всё остальное». Ваши правила остаются ниже. Всё применяется кнопкой «Сохранить и применить».
- **Предупреждения.** Если в выбранной базе geosite и geoip нет нужного списка, шаблон об этом пишет. Схема RoscomVPN рассчитана на базу hysteria-geodata.
- **Без шаблонов «программа».** На роутере правило выбирает устройства, а имена сайтов приложений роутер видит через свой DNS.

### Обновления

- **HyRouter.** «Настройки → Обновления»: роутер раз в сутки проверяет новую версию, а «Главная» о ней сообщает. Поставить её можно кнопкой «Обновить» или командой `hyrouterd -update` (на Кинетике — `/opt/sbin/hyrouterd -update`) по SSH. Пакет для вашей редакции и архитектуры скачивается с GitHub, сверяется с `SHA256SUMS` выпуска и ставится через `opkg` или `apk`. Служба перезапускается, и примерно полминуты сеть остаётся без интернета; настройки сохраняются. Если установка сорвётся, HyRouter всё равно запустится снова.
- **Ядра Hysteria и Xray** (обычная редакция). Новые стабильные выпуски проверяются по контрольным суммам и пробным запуском и ставятся кнопкой. Серверы на этом ядре перезапускаются; если те, что были подключены, не подключатся за минуту, вернётся прежнее ядро. Вернуть его можно и кнопкой. В Lite Hysteria встроена и обновляется вместе с HyRouter.
- **С 0.5.0 на 0.6.0** обновитесь вручную, как раньше: кнопка появилась только в этой версии.

### Обход DPI

- **Очередь 200.** nfqws2 раз за разом падал с `nfq_create_queue(): Operation not permitted`: очередь NFQUEUE 200 уже кто-то держал. Теперь HyRouter:
  - завершает nfqws2, оставшиеся от упавшего hyrouterd: сбросив права, nfqws2 переживал его и держал очередь;
  - если очередь занята другим обходом DPI (zapret, nfqws-keenetic), берёт свободные очереди 300 и дальше и называет эту программу на странице «Обход DPI». Два обхода мешают друг другу, а подбор видит чужую работу: оставьте один.
- **Подбор.** Если без обхода не ответило то, что обход не лечит (адрес не отвечает, имени нет в DNS), подбор проверяет ещё раз и только потом перебирает методы: случайный сбой больше не выдаёт себя за блокировку. Для «не нужен» страница показывает, какие адреса открылись с роутера без обхода.
- **PPPoE.** Сетью для запомненных методов считается само подключение (`ppp0`). Раньше страница писала «шлюз 0.0.0.0», и методы не запоминались.

### Какой пакет ставить

**OpenWrt.** Архитектуру покажут `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).

| Роутер | Архитектура | Пакет |
|---|---|---|
| MediaTek MT7981/MT7986/MT7988/MT7622, Qualcomm IPQ60xx/IPQ807x | `aarch64_cortex-a53` | `hyrouter` |
| Raspberry Pi 4 | `aarch64_cortex-a72` | `hyrouter` |
| другие aarch64 | `aarch64_generic` | `hyrouter` |
| x86_64 | `x86_64` | `hyrouter` |
| MediaTek MT7621 | `mipsel_24kc` | `hyrouter-lite` |
| Qualcomm IPQ40xx | `arm_cortex-a7_neon-vfpv4` | `hyrouter-lite` |
| Qualcomm IPQ806x | `arm_cortex-a15_neon-vfpv4` | `hyrouter-lite` |
| Marvell mvebu и др. ARMv7 | `arm_cortex-a9`, `arm_cortex-a7` | `hyrouter-lite` |

```sh
# OpenWrt 24.10
opkg update && opkg install ./hyrouter_0.6.0-1_aarch64_cortex-a53.ipk
# OpenWrt 25.x
apk update && apk add --allow-untrusted ./hyrouter-0.6.0-r1_aarch64_cortex-a53.apk
```

**Кинетик.** Архитектуру покажет `opkg print-architecture` в Entware.

| Архитектура Entware | Роутеры | Пакет |
|---|---|---|
| `mipsel-3.4` | большинство моделей (MediaTek MT7621, MT7628) | `hyrouter-keenetic-lite` |
| `mips-3.4` | некоторые модели | `hyrouter-keenetic-lite` |
| `aarch64-3.10` | новые модели на ARM64 | `hyrouter-keenetic` |

```sh
# скопировать на роутер: scp -P 222 -O пакет root@192.168.1.1:/opt/tmp/
opkg update
opkg install /opt/tmp/hyrouter-keenetic-lite_0.6.0-1_mipsel-3.4.ipk
```

Интерфейс — `http://192.168.1.1:8088` (адрес вашего роутера).
