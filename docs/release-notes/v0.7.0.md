В этом выпуске Hysteria встроена в HyRouter и в обычной редакции, VLESS стал модулем, который скачивается кнопкой. Ещё в нём то, что вышло в HyRoute с 1.3.26 по 1.3.34: обход DPI с исправлением застревающего видео YouTube, «Telegram без VPN» для всей сети, пинг и поиск серверов.

> [!WARNING]
> **Бета.** Полностью проверена только в CI: в сетевых пространствах имён Linux с настоящим сервером Hysteria 2 (обе редакции, OpenWrt и Кинетик, теперь без отдельного бинарника Hysteria на роутере), установкой и обновлением пакетов в образах OpenWrt 24.10 и 25.12 и в Entware. Telegram без VPN, пинг серверов и модуль VLESS проверены тестами, но не на настоящем роутере и не с настоящими серверами Telegram. Ставьте туда, где есть доступ по SSH, чтобы выключить HyRouter, если сеть перестанет работать:
> - OpenWrt: `/etc/init.d/hyrouter stop`, с «Блокировкой при загрузке» — ещё `/etc/init.d/hyrouter-guard disable && nft delete table inet hyrouter_guard`;
> - Кинетик: `/opt/etc/init.d/S99hyrouter stop`, с «Блокировкой при загрузке» — ещё `/opt/sbin/hyrouterd -cleanup`.

### Как обновиться

- С 0.6.0 — кнопкой «Обновить» в «Настройки → Обновления» или `hyrouterd -update` по SSH (на Кинетике — `/opt/sbin/hyrouterd -update`).
- С более ранних — вручную, как раньше (команды ниже).
- **Если у вас серверы VLESS** и Xray ещё ни разу не скачивался, после обновления нажмите «Скачать» у модуля VLESS в «Настройки → Модули». Если Xray уже был, модуль считается установленным, делать ничего не нужно.

### Hysteria встроена, VLESS — модуль

- **Hysteria 2 работает внутри HyRouter** и в обычной редакции, как в Lite. Отдельное ядро на 21 МБ больше не скачивается, и на каждый сервер не запускается отдельный процесс: меньше занято флеша и оперативной памяти. Скачанное прежними версиями ядро Hysteria удаляется при запуске и освобождает флеш. Встроенная Hysteria — 2.12.3; новые версии приходят с обновлениями HyRouter, поэтому обновления ядра Hysteria в «Обновлениях» больше нет.
- **VLESS — модуль.** В «Настройки → Модули» ядро Xray (около 32 МБ, архив 15 МБ) скачивается и удаляется кнопкой и сверяется по SHA-256. На флеш оно переезжает, если там есть место, иначе хранится во временном хранилище и после перезагрузки скачивается заново. Без модуля серверы VLESS не работают, и главная говорит почему. Маршрутизация при этом запускается, раньше её останавливало ядро, которое не скачалось.
- **Обновления ядра Xray**, когда модуль установлен, тоже идут через временное хранилище: на флеш попадает только само ядро. В 0.6.0 они требовали 48 МБ на флеше и не ставились на роутерах, где свободно меньше.

### Обход DPI (как в HyRoute 1.3.34)

- **Видео YouTube, которое долго грузилось.** Перебор методов считал неудачи серверов видео вместе со страницей youtube.com: страница открывалась, и метод, который не открывал видео, не менялся. Теперь у каждой группы серверов видео свой счёт, и подбор с самопроверкой проверяют серверы видео, которые устройства сети недавно спрашивали у DNS роутера. Их имена держатся только в памяти.
- **На плитке сервиса видно, каким методом обход работает сейчас** — для сайта и для групп серверов видео, — и сколько раз он переключался.
- **Новый метод** «Разрез с перекрытием под google.com, IP ID 0», как у Flowseal. Если ни один известный метод не помог, подбор пробует 26 рецептов zapret-discord-youtube (Flowseal) и kinlay0, а потом свои варианты с новыми приёмами: IP ID 0, сдвиги SEQ и ACK, нули перед фейком, фейк-копия настоящего начала соединения с чужим именем, разрез в семи местах.
- **Фейк портится старой меткой времени**, если у соединения есть метки времени (телефоны, Linux, macOS), иначе TCP MD5 (Windows). Порча выбирается для каждого пакета: в сети, где есть устройства и на Windows, и на других системах, метод работает для всех.
- Фейк QUIC отправляется 6 раз. Самопроверка нагружает роутер меньше, подбор, который она запускает сама, короче.

### Telegram без VPN

- **Переключатель на странице «Обход DPI».** Telegram на всех устройствах сети ходит к своим серверам через WebSocket веб-версии Telegram — эти адреса блокируют редко. На телефонах и компьютерах ничего настраивать не нужно.
- **Если WebSocket не отвечает,** Telegram идёт через Cloudflare (домены tg-ws-proxy или ваш Worker), основной сервер VPN или напрямую.
- **Самопроверка** раз в 5 минут; страница показывает, каким путём Telegram идёт сейчас.
- Звонки так не идут.

### Серверы и правила

- **Пинг одной кнопкой.** «Проверить показанные» измеряет пинг всех серверов, одной подписки, добавленных вручную или найденных поиском. Серверы запускаются по нескольку, а замеряются по одному, чтобы замеры не мешали друг другу. «По пингу» ставит самые быстрые наверх, щелчок по числу измеряет сервер заново.
- **Один список всех серверов,** своих и из подписок, с поиском и компактным видом: сервер в одну строку.
- **На странице «Правила»** — поиск по названию, сайтам, устройствам и серверу и компактный вид.

### Какой пакет ставить

**OpenWrt.** Архитектуру покажут `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).

| Роутер | Архитектура | Пакет |
|---|---|---|
| MediaTek MT7981/MT7986/MT7988/MT7622, Qualcomm IPQ60xx/IPQ807x | `aarch64_cortex-a53` | `hyrouter` |
| Raspberry Pi 4 | `aarch64_cortex-a72` | `hyrouter` |
| другие aarch64 | `aarch64_generic` | `hyrouter` |
| x86_64 | `x86_64` | `hyrouter` |
| MediaTek MT7621 | `mipsel_24kc` | `hyrouter-lite` |
| Qualcomm IPQ40xx | `arm_cortex-a7_neon-vfpv4` | `hyrouter-lite` |
| Qualcomm IPQ806x | `arm_cortex-a15_neon-vfpv4` | `hyrouter-lite` |
| Marvell mvebu и др. ARMv7 | `arm_cortex-a9`, `arm_cortex-a7` | `hyrouter-lite` |

```sh
# OpenWrt 24.10
opkg update && opkg install ./hyrouter_0.7.0-1_aarch64_cortex-a53.ipk
# OpenWrt 25.x
apk update && apk add --allow-untrusted ./hyrouter-0.7.0-r1_aarch64_cortex-a53.apk
```

**Кинетик.** Архитектуру покажет `opkg print-architecture` в Entware.

| Архитектура Entware | Роутеры | Пакет |
|---|---|---|
| `mipsel-3.4` | большинство моделей (MediaTek MT7621, MT7628) | `hyrouter-keenetic-lite` |
| `mips-3.4` | некоторые модели | `hyrouter-keenetic-lite` |
| `aarch64-3.10` | новые модели на ARM64 | `hyrouter-keenetic` |

```sh
# скопировать на роутер: scp -P 222 -O пакет root@192.168.1.1:/opt/tmp/
opkg update
opkg install /opt/tmp/hyrouter-keenetic-lite_0.7.0-1_mipsel-3.4.ipk
```

Интерфейс — `http://192.168.1.1:8088` (адрес вашего роутера).
