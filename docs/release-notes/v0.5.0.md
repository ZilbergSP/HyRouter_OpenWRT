В этом выпуске HyRouter работает и на роутерах Keenetic (и Netcraze) с KeeneticOS 4.x: тот же веб-интерфейс, те же правила, группы, подписки, geosite и geoip, обход DPI, статистика и резервная копия.

> [!WARNING]
> **Бета.** Проверена только в CI, на настоящих роутерах — ни на OpenWrt, ни на Кинетике — не проверялась. Для Кинетика CI проверяет правила через `iptables-restore --test`, маршрутизацию в сетевых пространствах имён Linux с настоящим сервером Hysteria 2 на legacy iptables (как в Entware), в том числе перестройку таблиц прошивкой, и установку пакета в Entware. Ставьте её туда, где есть доступ по SSH, чтобы выключить HyRouter, если сеть перестанет работать:
> - OpenWrt: `/etc/init.d/hyrouter stop`, с «Блокировкой при загрузке» — ещё `/etc/init.d/hyrouter-guard disable && nft delete table inet hyrouter_guard`;
> - Кинетик: `/opt/etc/init.d/S99hyrouter stop`, с «Блокировкой при загрузке» — ещё `/opt/sbin/hyrouterd -cleanup`.

### Кинетик

- **Что нужно.** KeeneticOS 4.x, компоненты «Поддержка открытых пакетов» (OPKG) и «Модули ядра подсистемы Netfilter» (на старых прошивках он появляется после компонента «Протокол IPv6»), Entware на USB-накопителе или во встроенной памяти.
- **Пароль.** В интерфейс HyRouter входят паролем root Entware. Стандартный пароль `keenetic` не подходит: смените его командой `passwd` в SSH Entware (порт 222).
- **Как работает.** Правила — на iptables и ipset из Entware (пакет ставит их сам). Имена сайтов HyRouter узнаёт через DNS прошивки, имена устройств и модель роутера — из её API. Интерфейс LAN по умолчанию — `br0` (домашний сегмент), гостевой можно добавить в настройках.
- **Правила после прошивки.** Когда Кинетик перестраивает свои правила (например, при переподключении к провайдеру), он убирает и правила HyRouter. HyRouter возвращает их сразу через хук прошивки и ещё раз проверяет каждые 15 секунд. Если пропадёт правило маршрутизации, VPN-трафик отклоняется, а не идёт напрямую.

**Чем Кинетик отличается от OpenWrt:**

- Блокировка при загрузке закрывает сеть только с запуска Entware: пока прошивка грузится и подключает накопитель, трафик идёт напрямую.
- Между перестройкой правил прошивкой и их возвратом новые соединения могут пройти мимо HyRouter: доли секунды, если сработал хук прошивки, до 15 секунд — если нет.
- DNS-фильтры Кинетика по отдельным устройствам видят роутер вместо устройства. Общие настройки DNS прошивки (DoH, DoT, фильтр для всей сети) работают.
- Если обход DPI работает через раз, попробуйте выключить сетевой ускоритель Кинетика: его состояние HyRouter прочитать не может, поэтому страница обхода напоминает об этом всегда.

### OpenWrt

- С включённой «Блокировкой при загрузке» hyrouterd закрывает сеть и при своём запуске — до того, как загрузит правила.
- Обновление с 0.4.0 сохраняет настройки в `/etc/hyrouter`.

### Какой пакет ставить

**OpenWrt.** Архитектуру покажут `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).

| Роутер | Архитектура | Пакет |
|---|---|---|
| MediaTek MT7981/MT7986/MT7988/MT7622, Qualcomm IPQ60xx/IPQ807x | `aarch64_cortex-a53` | `hyrouter` |
| Raspberry Pi 4 | `aarch64_cortex-a72` | `hyrouter` |
| другие aarch64 | `aarch64_generic` | `hyrouter` |
| x86_64 | `x86_64` | `hyrouter` |
| MediaTek MT7621 | `mipsel_24kc` | `hyrouter-lite` |
| Qualcomm IPQ40xx | `arm_cortex-a7_neon-vfpv4` | `hyrouter-lite` |
| Qualcomm IPQ806x | `arm_cortex-a15_neon-vfpv4` | `hyrouter-lite` |
| Marvell mvebu и др. ARMv7 | `arm_cortex-a9`, `arm_cortex-a7` | `hyrouter-lite` |

```sh
# OpenWrt 24.10
opkg update && opkg install ./hyrouter_0.5.0-1_aarch64_cortex-a53.ipk
# OpenWrt 25.x
apk update && apk add --allow-untrusted ./hyrouter-0.5.0-r1_aarch64_cortex-a53.apk
```

**Кинетик.** Архитектуру покажет `opkg print-architecture` в Entware.

| Архитектура Entware | Роутеры | Пакет |
|---|---|---|
| `mipsel-3.4` | большинство моделей (MediaTek MT7621, MT7628) | `hyrouter-keenetic-lite` |
| `mips-3.4` | некоторые модели | `hyrouter-keenetic-lite` |
| `aarch64-3.10` | новые модели на ARM64 | `hyrouter-keenetic` |

```sh
# скопировать на роутер: scp -P 222 -O пакет root@192.168.1.1:/opt/tmp/
opkg update
opkg install /opt/tmp/hyrouter-keenetic-lite_0.5.0-1_mipsel-3.4.ipk
```

Интерфейс — `http://192.168.1.1:8088` (адрес вашего роутера).
