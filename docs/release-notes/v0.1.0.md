Первый выпуск HyRouter: раздельная маршрутизация всей домашней сети через Hysteria 2 и VLESS на роутере с OpenWrt. Выходит в двух редакциях: **HyRouter** для aarch64 и x86_64 и **HyRouter Lite** для MIPS MT7621 и ARMv7.

> [!WARNING]
> **Бета.** Проверена только в CI: в сетевых пространствах имён Linux с настоящим сервером Hysteria 2 и установкой пакетов в официальные образы OpenWrt 24.10 и 25.12. На настоящих роутерах не проверялась. Ставьте её туда, где есть доступ по SSH: команда `/etc/init.d/hyrouter stop` возвращает сеть в состояние без HyRouter.

### Что умеет

- **Правила** по устройствам (MAC, IP, подсеть), сайтам (имя, сайт с поддоменами, IP, сеть), протоколу и портам. Действия: «через VPN», «напрямую», «блокировать», плюс правило «Всё остальное». Проверяются сверху вниз, срабатывает первое подходящее.
- **Серверы** добавляются по ссылкам `hysteria2://` и `hy2://`, в обычной редакции ещё `vless://`. Есть основной сервер, а у каждого правила может быть свой.
- **DNS роутера.** Адреса сайтов из правил попадают в наборы nftables раньше, чем ответ доходит до устройства. Имена сайтов «через VPN» разрешаются через VPN, поэтому провайдер их не видит и не может подменить.
- **TCP и UDP через VPN** (TPROXY). Прямой трафик решает ядро Linux, он не проходит через HyRouter и не замедляется.
- **VPN-трафик никогда не уходит напрямую.** Если сервер недоступен или hyrouterd упал, такие соединения отклоняются. procd сразу перезапускает hyrouterd.
- **Веб-интерфейс** на роутере: `http://<адрес роутера>:8088`, вход паролем root. Разделы: Главная, Серверы, Правила, Устройства (в том числе из списка DHCP), Журнал, Настройки.

### Какой пакет ставить

Архитектуру роутера покажут `opkg print-architecture` (OpenWrt 24.10) или `apk --print-arch` (OpenWrt 25.x).

| Роутер | Архитектура | Пакет |
|---|---|---|
| MediaTek MT7981/MT7986/MT7988/MT7622, Qualcomm IPQ60xx/IPQ807x | `aarch64_cortex-a53` | `hyrouter` |
| Raspberry Pi 4 | `aarch64_cortex-a72` | `hyrouter` |
| другие aarch64 | `aarch64_generic` | `hyrouter` |
| x86_64 | `x86_64` | `hyrouter` |
| MediaTek MT7621 | `mipsel_24kc` | `hyrouter-lite` |
| Qualcomm IPQ40xx | `arm_cortex-a7_neon-vfpv4` | `hyrouter-lite` |
| Qualcomm IPQ806x | `arm_cortex-a15_neon-vfpv4` | `hyrouter-lite` |
| Marvell mvebu и др. ARMv7 | `arm_cortex-a9`, `arm_cortex-a7` | `hyrouter-lite` |

```sh
# OpenWrt 24.10
opkg update && opkg install ./hyrouter_0.1.0-1_aarch64_cortex-a53.ipk
# OpenWrt 25.x
apk update && apk add --allow-untrusted ./hyrouter-0.1.0-r1_aarch64_cortex-a53.apk
```

Затем откройте `http://192.168.1.1:8088` (или адрес вашего роутера) и войдите паролем root. Если у root нет пароля, сначала задайте его командой `passwd`.

Ядро Hysteria 2 (и Xray для VLESS) в пакет не входит. HyRouter скачивает официальную сборку с GitHub при первом включении и сверяет её SHA-256. В HyRouter Lite при нехватке места на флеше ядро хранится в RAM и после перезагрузки скачивается заново.

### HyRouter Lite

Это та же программа с другими ограничениями: только Hysteria 2, кэш DNS на 10 000 записей, до 2048 соединений через relay одновременно, память hyrouterd ограничена 48 МБ. Рассчитана на роутеры с 256 МБ RAM, на 128 МБ — с оговорками. Скорость через VPN на таких процессорах ограничена шифрованием: ориентир — десятки Мбит/с. Прямой трафик идёт на полной скорости.
